# World Model Ball

Proyecto académico: aprendizaje de un World Model para la predicción de dinámica
y el control por imaginación en un entorno controlable de bola rebotante.

## Estado actual

En configuración inicial. Aún no implementado el entorno físico.

## Instalación

1. Crear entorno virtual: `python -m venv .venv`
2. Activar: `.venv\Scripts\Activate.ps1`
3. Instalar dependencias: `pip install -r requirements.txt`

## Estructura

- `environment/`: código del simulador de la bola (en construcción)
